# 会话标签分区 · DSH Session Tags

[English](./README.en.md)

为 DeepSeek Harness 桌面端添加自定义会话标签。将不同工作区中的会话归入「合金研究」「日常事务」等标签，在左栏集中查看。

## 功能

- **按标签分区**：标签显示在工作区上方，每个会话可归入一个标签。
- **双向拖动**：将工作区会话拖到标签即可归类；标签之间可直接拖动，拖到原工作区标题或其中任一会话即可移回。目标区域会高亮提示。
- **原生会话菜单**：标签内的会话点开 `⋯` 使用 Harness 原生会话菜单，置顶、重命名、分叉、归档等操作与「移至标签」并列；已归类的会话集中显示在标签下。
- **折叠与展开**：标签支持独立折叠，工作区沿用 Harness 的原生折叠功能。
- **连续滚动**：标签和工作区共用一个滚动区，左栏从上到下连续浏览。
- **跟随位置的小浮窗**：新建、移动、重命名和删除在按钮或点击位置附近展开，支持点击空白处或按 `Escape` 关闭。
- **保留原生操作**：标签内的会话继续使用置顶、重命名、分叉、归档等原生菜单操作。
- **本地保存**：标签和归类关系保存在本机，重启后继续使用；折叠状态保存在当前桌面客户端。

## 安装

### 在桌面端安装

1. 打开 **插件 → 添加插件**。
2. 填入以下地址并安装：

   ```text
   https://github.com/xty13114150041/dsh-session-tags/archive/refs/tags/v1.2.0.tar.gz
   ```

3. 完全退出并重新打开 DeepSeek Harness。

### 使用命令行

```bash
dsh plugin --profile desktop add https://github.com/xty13114150041/dsh-session-tags/archive/refs/tags/v1.2.0.tar.gz
```

安装完成后，完全退出并重新打开桌面端。

## 使用

| 操作 | 方法 |
| --- | --- |
| 新建标签 | 点击左栏「标签」旁的 `+`，输入名称并保存 |
| 将会话归入标签 | 拖到标签标题或标签区域，也可通过会话的 `⋯ → 移至标签` 菜单选择 |
| 在标签间移动 | 将标签内的会话拖到另一个标签；折叠的标签也可接收 |
| 移回工作区 | 拖到原工作区标题或其中任一会话，也可选择 `⋯ → 移至标签 → 移回原工作区` |
| 折叠或展开 | 点击标签名称左侧的箭头 |
| 重命名标签 | 打开标签的 `⋯` 菜单，选择「重命名标签」 |
| 删除标签 | 打开标签的 `⋯` 菜单，选择「删除标签」；其中的会话会回到原工作区，聊天记录保留 |
| 筛选会话 | 在标签区域的搜索框中输入会话名称或工作目录 |
| 刷新标签 | 点击「标签」旁的刷新按钮 |

会话归类保留原工作目录。切换标签后，继续使用原来的文件、工具和聊天记录。

## 兼容性

- **支持版本**：DeepSeek Harness Desktop `0.2.2-rc.1`（`engines.dsh: ^0.2.1-rc.5`，覆盖 0.2.x 系列）。
- **实测平台**：macOS。Windows 和 Linux 桌面端尚未验证。
- **界面适配**：复用 Harness 的主题颜色和原生会话菜单，当前已验证浅色主题。

插件依赖当前版本的侧栏组件接口。适配其他 Harness 版本时，需要重新验证侧栏和菜单。

## 智能体工具

可以通过 `session_tags` 工具管理标签，也可以执行 `/session-tags <JSON>` 命令。支持以下操作：

```json
{"action":"list"}
{"action":"create","name":"合金研究"}
{"action":"rename","tagId":"TAG_ID","name":"项目资料"}
{"action":"assign","tagId":"TAG_ID","sessionIds":["SESSION_ID"]}
{"action":"unassign","sessionIds":["SESSION_ID"]}
{"action":"delete","tagId":"TAG_ID"}
```

桌面界面、工具和命令共用同一份标签数据。界面操作通过本地认证接口读写数据。

## 开发

需要 Node.js 24 和 pnpm。

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm run check
```

测试覆盖标签状态操作、客户端挂载与卸载、原生会话菜单、桌面数据接口，共 22 项。桌面实测覆盖启动、标签增删改、双向拖动、标签间移动、折叠、原生菜单和小浮窗交互。

主要文件：

| 文件 | 用途 |
| --- | --- |
| `client.js` | 侧栏标签、原生会话菜单入口和小浮窗 |
| `host.js` | 持久存储、认证接口、工具和命令 |
| `model.js` | 标签与归类关系的状态操作 |
| `cordis.patch.yml` | Harness 插件入口 |
| `locale/` | 插件列表中的中英文介绍 |
